# Nebula TV

Un autre écran d'accueil pour les anciennes TV LG webOS.

## Le projet

Nebula remplace le menu d'accueil de webOS par une interface pilotable à la télécommande. Les raccourcis vers les applications sont personnalisables. Le comportement des boutons Home et Back, le réveil et le lancement de l'accueil font partie du projet.

Nebula n'a pas besoin d'Anime Sama, de Moonlight ni d'un serveur PC pour présenter l'accueil. Ces intégrations ne sont que des raccourcis facultatifs.

## Matériel

LG webOS

## Installation

Installation via un paquet IPK, après validation de la procédure et des services Home/Wake sur les versions compatibles.

## État

Les sources sont en cours de séparation de l'environnement de développement. Aucun IPK public validé pour l'instant.

Le dépôt sert pour l'instant à documenter le projet. Il ne contient pas encore de version à installer. Les premiers fichiers de code seront ajoutés après la vérification des informations privées et des droits de redistribution.
